

# Brain Tumor Detection

A MATLAB project that uses digital image processing techniques to analyse brain MRI images and highlight possible tumor regions.

## Requirements
- MATLAB
- Brain MRI image

## How to Run
1. Open `braintumordetector.m` in MATLAB.
2. Run the script and select an MRI image when prompted.
3. View the processed image and detection result.

## Note
This project is for educational purposes and is not a substitute for professional medical diagnosis.
